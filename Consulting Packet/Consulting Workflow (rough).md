# 2. Discovery/Scope -> Problem Statement

- Problem Statement
- Constraint List
- Success Criteria

	- Engagement type:
		- Fixed Scope
		- Exploratory

# 3. Proposal

- Scoped Problem -> Offer
- Purpose: (illegible) Minimal High Clarity Offer
- Artifacts:
	- 1-2 page proposal
	- Pricing model
		- [ ] fixed
		- [ ] retainer
		- [ ] diagnostic
	- timeline
	- list of deliverables
	- assumptions & exclusions
	- proposal structure:
		- Problem (in their words, clarified by you)
		- Impact (cost to client, not necessarily $)
		- Approach to resolution
		- Deliverables
		- timeline breakdown (phases, not dates)
		- Investment?
		- Next steps:
			- contract
			- deposit
			- 30-50% up front
	- Exit condition: Client says yes

# 6. Delivery & Checkpoints

- Execution outcomes
- purpose = execute work with predictable cadences
- artifacts
	- bi/weekly updates
	- milestone reviews
	- risk updates
	- deliverables
	- COT (change order triggers if needed)
	- Exit cinditions: All deliverables met & accepted
	- Delivery style:
		- Operator grade clarity
		- minimalist docs
		- no surprises
		- transparent blockers
		- modular outputs for client maintenance
