# SDLC Directory Overview

This directory contains all governance, SDLC, character, and oversight materials for the KNLK project.  
It is organized into three layers:

1. **Strategic** — Project Charter  
2. **Operational** — SDLC Execution  
3. **Reference** — SDLC Starter Kit  

It also includes the character system and Gordon’s oversight templates.

---

# 1. Strategic Layer

## `KNLK-Project-Charter.md`

Defines:

- project purpose  
- stakeholder and contracted roles  
- scope and constraints  
- governance model  
- SDLC structure  
- approval and escalation paths  

This is the highest‑authority document in the SDLC directory.

---

# 2. Operational Layer

## `KNLK-SDLC-Execution.md`

Executes the SDLC phases for the KNLK project:

- Planning  
- Requirements  
- Design  
- Development  
- Testing  
- Deployment  
- Maintenance  

Each phase includes deliverables, workflows, and responsibilities.

---

# 3. Reference Layer

## `SDLC Starter Kit Packet.md`

A library of reusable SDLC templates:

- Project Plan  
- SRS  
- HLD  
- LLD  
- Test Plan  
- Deployment Plan  
- Maintenance Plan  

These templates are generic and not tied to KNLK.

---

# 4. Character System

## `Characters/`

Contains:

- Character template  
- Gordon, PPM  
- Kuber Netty, SRE  
- Patch  

Each character is an independent corporate entity with defined responsibilities.

# 6. Purpose of the SDLC Directory

This directory provides:

- a complete governance system  
- a structured SDLC execution model  
- character‑based operational roles  
- oversight routines  
- reusable templates  

It is the authoritative operational layer of the KNLK project.
